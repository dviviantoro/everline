1) Deskripsi Perubahan

Starts the Android field-capture app described in ADR-002 and ADR-003. Adds the decision records and design doc, a Rust workspace (`mobile/rust`) with a placeholder Red Pitaya link protocol, a severity classifier, a thin WASM facade and a simulated Red Pitaya, and a Capacitor 8 app shell (`mobile/`) whose single screen replays the Rust golden vectors through the WASM module inside a Web Worker. The debug APK builds with the pinned JDK 21. Nothing was run on a phone yet: none was attached. The hotspot and Red Pitaya reachability spike, the VPS CORS change and the WebView checks remain open under TASK-004.

2) Tujuan dan Manfaat

- Record the scope override (native app, live telemetry, offline capture were non-goals) in an ADR and the CHANGELOG, as the contract requires.
- Prove the cross-target correctness of the decoder before any feature UI exists: one set of golden vectors must give identical results natively, in Node and in a browser Worker (the Android WebView is the fourth runtime, still to do).
- Make the whole pipeline testable without Red Pitaya hardware through the simulated device.
- Pin the toolchain (JDK 21, Rust 1.97.1, wasm-bindgen CLI/crate match) so builds are reproducible on this Mac.
